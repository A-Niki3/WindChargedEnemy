
# WindChargedEnemy

## WindChargedEnemyへようこそ
このたびはWindChargedEnemy(以下wce)にアクセスいただきありがとうございます。
wceは敵対するモンスターの攻撃にウィンドチャージの効果を付与するmodです。

Ragdoll modと組み合わせると地獄のような難易度になるので併用をおすすめしております。

## 遊び方
### 1. 導入
Modを[ダウンロード](<https://github.com/A-Niki3/WindChargedEnemy/releases>)<br>
※CurseForgeでの展開も予定

NeoForge 26.2.0.95以上の環境のmods📁フォルダに入れて起動<br>
※NeoForge以外に前提modは必要ありません

### 2. 設定
modの設定画面またはconfig/wce/common.tomlからmodの有効化設定やデフォルトの発生確率を変更可能です。

エンティティ別の設定はゲームプレイ中にエンティティから攻撃を受けることで`config/wce/entities/`内に<br>
`minecraft/zombie.json`や`mod/modEntity.json`のように追加されていきます。
